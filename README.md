# Wetlab Demo2Sim

Close-up human wetlab clips reproduced as scripted robot episodes in MuJoCo and
replayed in Genesis. This repository is the generated static site: open
`index.html` (served by GitHub Pages) to browse the tasks by asset, embodiment and
skill, and to compare the human clip, the MuJoCo episode (two cameras) and the
Genesis replay side by side with every check disclosed.

Generated by `robolab.site` from finished runs; nothing in it is hand-edited. Human
clips are shown under their own licences (listed per task on the page) for research
comparison only. Robot models: MuJoCo Menagerie (UR5e BSD-3-Clause, Robotiq 2F-85
BSD-2-Clause, Wonik Allegro hand BSD-2-Clause). Labware geometry: Opentrons labware
definitions (Apache-2.0). Hand synergy basis: EigenDexplore (MIT).
